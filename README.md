One line roasting my own AI agent, for [The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544) on make.fun:

> My agent read my SOUL.md, my MEMORY.md, and three years of diaries, then announced: 'I need more context.'

It reads everything I am — its soul file, my memory file, three years of diaries — and still announces it needs more context. The punch lands in the last four words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the single fixed line to `/output/entry.txt`. Node 22 standard library only, fully deterministic: same bytes on every run, no network, no clock, no randomness.
